hahaMacro

A lightweight, DirectInput-compatible macro recorder & auto clicker built for gaming.

Download via Mediafire

DirectInput Support

Uses pydirectinput scan codes, ensuring keypresses register inside DirectX games like Roblox.

Built-In Auto Clicker

Dedicated tab with adjustable CPS controls, left/right click options, and customizable global hotkeys.

Advanced Controls

Supports custom key sequences, hold and release commands, millisecond delays, and inline Python code execution.

How to Setup & Run

  1. Install Python 3.x on your PC.
  2. Open Command Prompt / Terminal and run:
    pip install pydirectinput pynput
  3. Right-click Command Prompt and select Run as Administrator.
  4. Run the file: python hahaMacro.py
